# GitHub Pages 公開上傳包

這個資料夾只包含公開網站所需的頁面與圖片，已排除行程生成器、內部行程資料、備份與管理系統文件。

## 上傳方式

1. 開啟 GitHub 的網站 repository。
2. 將**本資料夾內的所有內容**上傳到 repository 根目錄；不要把整個「GitHub_Pages_公開上傳包_2026-08-11」資料夾再包一層上傳。
3. 確認 repository 根目錄可直接看到 `index.html`、`web-assets`、`詳細行程`、`北海岸精選行程測試` 與 `精選行程網站圖片`。
4. 到 GitHub repository 的 **Settings → Pages**，選擇要發布的 branch（通常是 `main`）及 **/(root)**，再儲存。
5. 等待 GitHub Pages 完成部署後，開啟網站並逐一測試首頁圖片、每一個「查看行程」、返回精選行程按鈕，以及 LINE／WhatsApp 按鈕。

## 注意事項

- 請保持資料夾與檔案名稱完全相同，尤其是中文名稱與 `LINE_WhatsApp測試` 檔名。
- 本包目前使用測試版聯絡方式：LINE 與 WhatsApp（+886 935 089 253）。正式測試完成前，不需覆蓋原始網站檔。
- `.nojekyll` 已包含在內，避免 GitHub Pages 略過網站資源。
